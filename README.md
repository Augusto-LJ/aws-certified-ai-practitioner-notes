# 🤖 AWS AI Practitioner (AIF-C01) - Resumo dos conteúdos

## 🎯 Objetivo

Este repositório foi criado para servir como um **guia prático e direto ao ponto** para quem está se preparando para a certificação **AWS Certified AI Practitioner (AIF-C01)**.

O foco é reunir **resumos claros, organizados e voltados para a prova**, abordando os principais conceitos de Inteligência Artificial, Machine Learning, IA Generativa, IA Responsável e os serviços de IA da AWS, evitando conteúdo excessivamente teórico ou disperso.

---

## 🚀 Para quem é este repositório

Este material é ideal para:

- Iniciantes em Inteligência Artificial e Machine Learning
- Pessoas estudando para a certificação AWS AI Practitioner (AIF-C01)
- Quem deseja revisar rapidamente os principais conceitos antes da prova
- Desenvolvedores, analistas e profissionais de tecnologia que desejam compreender os fundamentos de IA e os serviços de IA da AWS

---

## ⚠️ Para quem NÃO é

Este repositório **não é indicado** para:

- Quem busca conteúdo avançado sobre Machine Learning ou Deep Learning
- Preparação para certificações mais avançadas, como AWS Machine Learning Engineer ou AWS Machine Learning Specialty
- Estudos aprofundados sobre algoritmos, matemática ou implementação de modelos de IA

## 🎯 Foco na certificação

Todo o conteúdo foi organizado pensando na prova da **AWS AI Practitioner (AIF-C01)**.

Por isso, os resumos priorizam:

- Conceitos cobrados na certificação
- Diferenças entre serviços da AWS
- Comparações frequentes em provas
- Pegadinhas comuns

Sempre que possível, cada assunto também apresenta exemplos práticos para facilitar a memorização.

### 🛠️ Como contribuir

1. Faça um **fork** do repositório
2. Crie uma branch para sua alteração:
   - `git checkout -b minha-melhoria`
3. Faça as alterações
4. Commit:
   - `git commit -m "feat: melhora conteúdo sobre Amazon Bedrock"`
5. Envie para o seu fork:
   - `git push origin minha-melhoria`
6. Abra um **Pull Request**

### 📌 Boas práticas

- Siga o padrão dos arquivos existentes
- Mantenha o conteúdo objetivo e focado na certificação
- Evite textos excessivamente longos
- Utilize emojis e a estrutura já adotada no projeto
- Caso tenha dúvidas, fique à vontade para abrir uma **issue** 🙂
