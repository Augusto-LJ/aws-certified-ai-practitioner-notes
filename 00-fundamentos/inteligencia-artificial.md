# 🤖 Fundamentos de Inteligência Artificial (Artificial Intelligence - AI)

## 📌 O que é

Inteligência Artificial é um campo amplo que engloba o desenvolvimento de sistemas inteligentes capazes de realizar tarefas que, normalmente, requerem inteligência humana

📌 Essas tarefas incluem:
- Tomada de decisão
- Reconhecimento de padrões
- Compreensão de linguagem
- Resolução de problemas

---

## 🎯 Quando usar

- Quando é necessário automatizar decisões
- Quando há grande volume de dados
- Quando regras fixas não são suficientes

- Ex:
  - Chatbots
  - Recomendação de produtos
  - Reconhecimento de imagem
  - Assistentes virtuais

---

## ⚙️ Como funciona

A IA utiliza:
- Dados
- Algoritmos
- Modelos matemáticos

Fluxo básico:

1. Coleta de dados  
2. Processamento  
3. Aprendizado de padrões  
4. Tomada de decisão ou geração de resposta  

📌 A IA moderna é fortemente baseada em Machine Learning

## 🌎 Casos de uso de IA (AI Use Cases)

A IA está sendo utilizada em diversos setores para:
- Automatizar tarefas
- Melhorar experiências
- Reduzir custos
- Aumentar produtividade
- Apoiar tomada de decisão

---

### 🎬 Mídia e entretenimento (Media & Entertainment)

A IA pode ser usada para:

- Geração de conteúdo
  - Criação de roteiros
  - Geração de histórias
  - Criação de diálogos

- Realidade virtual (Virtual Reality)
  - Ambientes imersivos
  - Simulações interativas

- Geração de notícias
  - Resumos automáticos
  - Criação de artigos com base em eventos

- Ex:
  - Streaming
  - Jogos
  - Produção audiovisual

---

### 🛒 Varejo (Retail)

A IA pode ser usada para:

- Resumo de avaliações de produtos
  - Identificar rapidamente pontos importantes

- Otimização de preços
  - Ajuste dinâmico de preços
  - Maximização de lucro

- Experiências virtuais
  - Experimentação virtual de roupas/produtos

- Otimização de layout
  - Melhor organização de lojas

- Sistemas de recomendação
  - Produtos sugeridos para clientes

- Ex:
  - E-commerce
  - Marketplaces
  - Aplicativos de compras

## 🧠 Conceitos importantes para prova

- IA pode ser aplicada em praticamente qualquer setor
- Generative AI é muito usada para:
  - Texto
  - Código
  - Imagem
  - Resumos
- IA ajuda em:
  - Automação
  - Personalização
  - Otimização
- AWS oferece serviços específicos para vários casos de uso

---

## ⚠️ Pegadinhas comuns

- IA ≠ apenas chatbots
- Generative AI ≠ única forma de IA
- Nem toda IA cria conteúdo
- Muitos casos de uso utilizam ML tradicional
