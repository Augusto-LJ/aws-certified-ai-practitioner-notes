# 🔄 Ciclo de Vida de Machine Learning (ML Lifecycle)

## 📌 O que é

O **ciclo de vida de Machine Learning (ML Lifecycle)** representa todo o processo necessário para desenvolver, implantar, monitorar e manter um modelo de Machine Learning em produção.

É um processo **iterativo**, pois frequentemente é necessário voltar às etapas anteriores para melhorar o desempenho do modelo.

## 🎯 Objetivo

O ciclo de vida de ML organiza todas as etapas envolvidas no desenvolvimento de uma solução de Machine Learning, desde a identificação do problema até o monitoramento do modelo em produção.

Seu objetivo é garantir que o modelo:

- Resolva um problema de negócio
- Seja treinado com dados de qualidade
- Produza previsões confiáveis
- Continue apresentando bom desempenho ao longo do tempo

📌 O desenvolvimento de um modelo de ML não termina quando ele é implantado. O monitoramento e o retreinamento fazem parte do processo.

---

## 🗺️ Etapas do ciclo de vida de ML

O ciclo de vida de Machine Learning normalmente é composto pelas seguintes etapas:

1. 🎯 Definição das metas de negócio
2. 🧩 Formulação do problema de ML
3. 📊 Processamento dos dados
4. 🤖 Desenvolvimento do modelo
5. 🚀 Implantação do modelo
6. 📈 Monitoramento
7. 🔄 Retreinamento

---

## 🧠 Etapas iniciais

### 🎯 Definição das metas de negócio

Todo projeto de Machine Learning começa com um **problema de negócio**, e não com tecnologia.

Nesta etapa são definidos:

- Objetivos do projeto
- Valor esperado para a empresa
- Orçamento
- Critérios de sucesso
- KPIs (Key Performance Indicators)

Os KPIs permitem medir se o modelo realmente resolveu o problema proposto.

📌 O objetivo é responder perguntas como:

- Qual problema queremos resolver?
- Qual impacto esperamos gerar para o negócio?
- Como saberemos se o projeto foi bem-sucedido?

---

### 🧩 Formulação do problema de Machine Learning

Após entender o problema de negócio, ele precisa ser convertido em um problema de Machine Learning.

Essa etapa envolve responder perguntas como:

- Machine Learning realmente é a solução?
- Existem dados suficientes?
- Há conhecimento técnico disponível?
- O problema é de classificação, regressão ou outro tipo?

Normalmente participam dessa fase:

- Cientistas de Dados (Data Scientists)
- Engenheiros de Dados (Data Engineers)
- Arquitetos de ML (ML Architects)
- Especialistas do negócio (SMEs - Subject Matter Experts)

📌 Um problema de negócio precisa ser traduzido para um problema que possa ser resolvido por um modelo de Machine Learning.

---

## 🔁 Natureza iterativa

O ciclo de vida de Machine Learning **não é linear**.

Após o treinamento, avaliação ou implantação, pode ser necessário retornar às etapas anteriores para:

- Coletar novos dados
- Melhorar a qualidade dos dados
- Criar novas features
- Ajustar hiperparâmetros
- Retreinar o modelo

Esse processo contínuo permite melhorar o desempenho do modelo ao longo do tempo.

---

## 🔁 Comparações importantes

### Problema de negócio vs Problema de Machine Learning

| Problema de negócio | Problema de ML |
|----------------------|----------------|
| Define o objetivo da empresa | Define como a IA resolverá o problema |
| Focado em valor para o negócio | Focado em previsão ou aprendizado |
| Ex.: reduzir transferências | Ex.: prever o atendente correto |

---

## 🧠 Conceitos importantes para prova

- Todo projeto de ML começa com um **problema de negócio**
- O problema de negócio deve ser convertido em um **problema de Machine Learning**
- O ciclo de vida de ML é **iterativo**
- Implantar um modelo **não encerra** o projeto
- O monitoramento e o retreinamento fazem parte do ciclo de vida
- KPIs são utilizados para medir o sucesso da solução

---

## ⚠️ Pegadinhas comuns

- Machine Learning **não começa pelo treinamento**, mas pelas metas de negócio
- O problema de negócio e o problema de ML **não são a mesma coisa**
- O ciclo de vida **não é um processo linear**
- Implantar o modelo **não encerra** o ciclo de vida
- Melhorar um modelo frequentemente exige retornar a etapas anteriores

---

## 🔁 Resumo rápido

- O ciclo de vida de ML representa todas as etapas necessárias para desenvolver e manter um modelo
- O processo começa pela definição das metas de negócio
- O problema de negócio deve ser convertido em um problema de Machine Learning
- O ciclo é iterativo e envolve monitoramento e retreinamento contínuos
